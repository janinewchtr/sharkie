# Sharkie

Sharkie is a browser-based jump-and-run game built with JavaScript, HTML, and CSS. The player helps Sharkie collect coins and poison bottles while avoiding enemies in an underwater game world.

## Features

- Keyboard-controlled character movement
- Collectable coins and poison bottles
- Enemy collision detection
- Animated game objects
- Health, coin, and bottle status bars
- Endboss fight
- Start screen, game over screen, and win screen

## Technologies

- HTML
- CSS
- JavaScript
